# Operations Runbook

## Daily
- Monitor low-stock and out-of-stock reports.
- Check failed payment logs per gateway.
- Validate overnight backup completion.

## Weekly
- Run plugin/theme update check in staging first.
- Review abandoned carts and trigger recovery workflows.
- Validate indexing health and schema rich result coverage.

## Monthly
- Performance audits (Core Web Vitals).
- Pen-test/security scan.
- Validate shipping SLA by zone and pincode success rates.
